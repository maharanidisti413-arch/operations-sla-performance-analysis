# Operations & SLA Performance Analysis

An anonymized operational dataset used to analyze workload, SLA performance, and operational patterns.

## Project Overview

This project demonstrates data cleaning, KPI analysis, and dashboard development using Excel.

## Analysis Scope

The analysis focuses on operational records from the available dataset for August 2026.

## Tools

- Microsoft Excel
- Data Cleaning
- PivotTables
- KPI Analysis
- SLA Analysis
- Dashboarding

## Data Privacy

The dataset has been anonymized for portfolio purposes. Original customer, business, agent, and company identifiers are not included.

## Project Structure

- `data/` — anonymized analysis datasets
- `docs/` — data dictionary
- `excel/` — Excel analysis and dashboard

## Note

This is a portfolio project created for learning and career demonstration purposes.
